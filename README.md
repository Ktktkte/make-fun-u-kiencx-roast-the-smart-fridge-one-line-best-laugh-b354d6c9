One line, 133 characters, roasting the smart fridge — its internal camera emailed me a photo of my 2am ice cream. Entry for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty ($2 in USDC).

The entry program (`main.ts`, Node 22) reads the roast from `entry.txt`, validates it against the gate (1–160 characters, not only whitespace, a single line), and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Run twice from any directory — the output is byte-identical both times.
